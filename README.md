## 近期学习笔记

### 笔记一：语音离散表征能保留多少说话人信息？

- 问题：把音频压成离散 token 后，说话人身份是否还容易被下游模型恢复？
- 方法：用预训练模型抽取离散表征，训练一个轻量说话人分类器，并和随机初始化基线对比。
- 下一步：在噪声条件下重复实验，观察离散表征的说话人鲁棒性是否稳定。

### 笔记二：低资源语音微调为什么容易过拟合？

- 问题：在几百小时数据上微调语音大模型时，验证集损失经常先降后升。
- 方法：记录不同层参数的梯度范数变化，定位最先出现过度适应的那部分网络。
- 下一步：尝试冻结高层语义特征、只微调低层特征，比较对低资源任务的泛化影响。

### 笔记三：如何稳定评测生成式语音对话模型？

- 问题：传统 ASR 的 WER 无法完整反映生成式语音模型的对话质量。
- 方法：整理一组带难度标注的中文测试句，同时使用客观指标和人工评分做对比。
- 下一步：把评测结果做成一个小的可视化面板，方便快速查看失败案例。
